# AI Disclosure

I have used an AI coding assistant (Claude Opus 5) while writing the C++ code for this mod. Every design decision, and every feature, and all of the art, UI layout and video is mine. No generative AI was used for any of the media. The mod itself contains no AI and doesn't connect to anything.

## What I used it for

Auto Rail Supports is heavily based on C++ code, and I used Claude Opus 5 to help code it. 

Satisfactory modding means reading a large codebase. I have used claude to research and pull relevant lines from this codebase.

I have used claude to write debugging code and skim through log files for finding bugs or other issues.

## What I did not use it for

No generative AI in any of the media. The mod icon, any of the UE assets/widgets and the mod trailer are all made by hand. 

## Why say anything?

Not everyone wants to engage with content created with any type of generative AI. I'd rather be straightforward and honest, so you can weigh it however you like and not feel misled.

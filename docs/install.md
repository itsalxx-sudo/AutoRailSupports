# Installation

## Use the Mod Manager

Install Auto Rail Supports through the **[Satisfactory Mod Manager](https://ficsit.app/)**.

1. Install the Mod Manager if you don't have it.
2. Search for **Auto Rail Supports**.
3. Click Install.
4. Launch the game from the Mod Manager.

**Requires:** SML `3.12.0` or newer.

## Multiplayer

Auto Rail Supports must be installed by **both the host and every client**.

## Dedicated servers

The mod builds for Windows and Linux dedicated servers as well as the game client. Install it on
the server through the Mod Manager's server management.

## Uninstalling

Turn the mod off in the Mod Manager.

Supports you already built are **normal buildings**, they stay in your save and behave like
anything else you built by hand. Nothing disappears and nothing breaks. Your ARS *settings* stay
stored in the save and come back if you reinstall.
